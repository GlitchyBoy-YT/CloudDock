Welcome to CloudDock

CloudDock is being developed as a unified hosting platform for game servers, Discord bots, websites, virtual servers, and databases. The goal is to make it easier to understand your options and manage your projects from one place.

Choosing a hosting product

Start with what you're trying to run. A Discord bot needs an application runtime; a website needs static or application hosting; a game server needs compatible compute, storage, and network capacity. Review the requirements before choosing a plan.

Prepare to deploy

  • Confirm the software and version you plan to run.
  • Estimate memory, storage, and network requirements.
  • Keep backups of important project data.
  • Review acceptable-use and service terms before deployment.

Security basics

Use unique passwords and enable multi-factor authentication when available. Never share passwords, API keys, access tokens, or recovery codes. Support staff should not need your password to troubleshoot an issue.

Common questions

Can I order hosting today?

Not yet. CloudDock is in development; this website is an early preview.

Does GitHub Pages run my servers?

No. GitHub Pages serves this static frontend. Hosting workloads require separate backend APIs and compute infrastructure.

Where can I follow development?

Visit the CloudDock GitHub repository.
