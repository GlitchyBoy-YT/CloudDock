LEGAL INFORMATION

Privacy, by design.

A preliminary privacy notice describing the current static website preview.

Draft — verify before launch

This is not a finalized privacy policy or legal advice. The project operator must verify actual hosting, analytics, authentication, database, and support data flows before enabling those features.

1. Current website preview

This static preview does not currently provide CloudDock account registration, payment checkout, or a first-party support form. GitHub links open services operated by GitHub, which process information under their own privacy terms. The website hosting provider may process technical request information to deliver the site and maintain security.

2. Local preferences

The theme switcher stores a dark or light preference in the visitor's browser using local storage. That preference is not sent to a CloudDock account or database by this static preview.

3. Information not requested here

Do not submit passwords, API keys, access tokens, financial information, or sensitive personal information through public issue trackers or project discussions.

4. Future services

Before accounts or hosting services launch, this notice must be updated to describe the actual information collected, purposes, legal basis where applicable, service providers, retention periods, security practices, and available privacy choices.

5. Third-party links

Links to GitHub and other external websites are provided for convenience. Their privacy practices are governed by their own policies.

6. Contact

For questions about the project preview, use the support page and avoid posting private information publicly.
