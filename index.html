GOOD TO KNOW

Frequently asked questions.

Can I host more than Discord bots?

CloudDock plans Discord, Nerimity, Fluxer and Stoat bot hosting, plus Minecraft and website hosting.

Does signing up start a server?

No. Creating an account gives you access to the customer dashboard. Real deployments require the hosting API and worker infrastructure, which are still being built.

Can I manage files and backups?

These are core planned panel features and will be enabled service-by-service as the production backend is built.

Where are the servers located?

US and EU regions are planned. Exact regions and availability will be published before services are offered.

GETTING STARTED

Documentation

How CloudDock will work

1. Create a bot application and select its platform.

2. Connect a secure backend that stores encrypted credentials.

3. Submit deployments to a job queue.

4. Run each bot in an isolated worker container with resource limits.

GitHub Pages hosts this dashboard only. It cannot run persistent Discord, Nerimity, Fluxer, or Stoat bots.
