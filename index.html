CloudDock is currently in development. This website is an early public preview; purchasing and service provisioning are not available yet.

The planned categories include Minecraft, other game servers, Discord bots, websites, virtual private servers, and databases.

A unified control panel is part of the product direction. Its features and supported integrations will be announced as development progresses.

Visit the CloudDock GitHub repository to follow changes, report issues, and see what is being worked on.
